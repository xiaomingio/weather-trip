Two instruments

两种进入天气的方式

不是内容合集，而是可直接操作的地图与筛选工具。

01 Map

全球天气地图

先看见世界各地正在发生的天气

选择某一天，在地图上浏览气温、天气类型、降水、湿度、海拔与舒适度。 支持全球、大区、国家与中国省级聚焦。

02 Match

按天气找城市

先写下你想要的天气，再找城市

设定温度区间、晴雨、湿度、海拔与出行天数（3 / 5 / 7 / 10 / 14）。 城市按匹配天数与平均温度排序，适合反向规划行程。

How it reads

像读画册一样使用工具

  1. 一

    选一条路径

    从全球天气地图浏览，或从天气偏好反向匹配城市。顶部 Tab 随时切换。

  2. 二

    收窄时间与地区

    地图按日期查看；匹配工具按计划天数截取预报窗口，短途与长途各自计算。

  3. 三

    点开城市细读

    选中城市后阅读未来两周的温度、天气、湿度与降水，再决定是否出发。
