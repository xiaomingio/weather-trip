# Weather Trip Product Design

## 产品定位

Weather Trip 是一个用天气判断城市的双语工具站。用户可以先看全球城市未来天气，也可以先输入温度、晴雨、湿度、海拔和时间窗口偏好，再通过地图和结果列表找到更适合出发的城市。

## 产品范围

Weather Trip 包含一个 Landing page 和两个工具 Tab，支持中文和英文入口：

```text
/              # 英文首页
/weather-map   # 英文全球天气地图
/city-finder   # 英文按天气找城市
/zh            # 中文首页
/zh/weather-map # 中文全球天气地图
/zh/city-finder # 中文按天气找城市
```

首页负责说明产品判断方式和导流；工具页直接提供可操作的数据工作区。

## 主要任务

| 任务 | 说明 |
| --- | --- |
| Landing page | 默认语言入口，无额外 mode path；展示产品定位、数据覆盖证据，并进入两个工具 Tab |
| 全球天气地图 | 选择某一天，在地图上查看气温、天气、降水、湿度、海拔和舒适度；整体交互见 `docs/specs/20-interaction-logic.md`，城市覆盖和区域着色规则见 `docs/specs/30-weather-coverage-design.md`，地图 hover、点位密度和地区控件交互见 `docs/specs/22-weather-map-interactions.md` |
| 按天气找城市 | 按未来 3/5/7/10/14 天筛选城市，展示匹配天数和平均温度 |
| 地区聚焦 | 支持全球、大区、C2/C3 国家，以及国家内一级区域筛选；C3 二级区域用于地图着色和 hover，不进入筛选下拉 |
| 城市详情 | 选中城市后展示未来 14 天温度、天气、湿度和降水 |
| 双语体验 | 默认英文路径不加语言前缀，中文路径加 `/zh`；UI 控件、图例、结果摘要和城市名称支持中文/英文 |
| 温度单位 | 顶部控件支持摄氏度和华氏度切换，偏好保存在浏览器本地 |

## 路径与状态

两个工具 Tab 使用路径区分：英文为 `/weather-map`、`/city-finder`，中文为 `/zh/weather-map`、`/zh/city-finder`。筛选条件放在各自路径的 query 中，便于刷新和分享，且两个 Tab 不复用同一套 query：

| 路径 | 写入 / 恢复的 query |
| --- | --- |
| `/weather-map`、`/zh/weather-map` | `region`、`date`、`layer` |
| `/city-finder`、`/zh/city-finder` | `region`、`days`、`temp`、`weather`、`humidity`、`precipitation`、`wind`、`elevation` |

切换 Tab 时恢复目标 Tab 自己上次使用的条件，不把当前 Tab 的条件带到另一 Tab。

全球天气地图的 `date` 是所选地区可用日期里的实际本地自然日。不同地区因为时区和天气源返回窗口不同，可用日期集合的头尾可能不一样；用户切换地区时，按日期滑块的相对位置迁移，例如当前选第 3 天，切到新地区后也选新地区的第 3 天，并把新的实际 `date` 写回 URL。

## 地区选择

地区选择以用户能理解的旅行范围为入口：全球、大区、国家和国家内一级区域。C3 二级区域用于地图表达更细的天气差异，但不作为筛选入口，避免用户在下拉里面对过细的行政层级。

地区筛选、日期、图层、列表排序和默认选中规则见 `docs/specs/20-interaction-logic.md`。地区覆盖、地图着色粒度和区域点击规则以 `docs/specs/30-weather-coverage-design.md` 为准；地区控件、hover 和 marker 交互见 `docs/specs/22-weather-map-interactions.md`。

## 旅行时间窗口

系统保留未来 14 天天气数据，但用户不一定在规划 14 天行程。按天气找城市的 `days` 表示本次计划长度，支持 3、5、7、10、14 天；推荐分数、匹配天数、区域着色和结果排序都只使用从当前可用预报开始截取的这段窗口。

14 天是数据缓存上限，不是默认假设的旅行长度。短途旅行用户选择 3 天或 5 天时，城市只需要在短窗口内满足天气偏好；长途旅行用户选择 10 天或 14 天时，系统再按更长窗口计算稳定性。

## 视觉方向

首页使用简洁首屏承接产品定位、数据覆盖和两个工具入口；工具页是数据工作区，地图占据主要视觉面积，筛选、结果和未来天气条围绕地图组织。色彩保持中性地图底色，搭配温度、天气、湿度和舒适度色带。
