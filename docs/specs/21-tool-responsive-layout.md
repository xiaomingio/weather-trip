# Tool Responsive Layout

## 适用范围

本文档定义首页、`/weather-map`、`/city-finder`、`/zh/weather-map` 和 `/zh/city-finder` 的顶部导航，以及两个工具 Tab 的响应式布局规则。它是顶部导航和工具页响应式行为的验收规范，不替代具体 CSS 实现。

## 设计归属

| 对象 | 规则 |
| --- | --- |
| 顶部导航 | 首页和两个工具页共用同一套结构、断点、字号、Tab 尺寸、颜色变量和按钮尺寸 |
| Landing page | 使用同一套顶部导航；页面内容只定义首页 hero 和导流内容，不改写导航规则 |
| 工具页外壳 | 顶部导航先出现，工具工作区后出现；两者在布局上是兄弟关系 |
| City Finder 工作区 | 承载筛选、城市列表、未来天气条、地图和 URL 状态 |
| Weather Map 工作区 | 承载地区、日期、图层、排序、地图视图和 URL 状态 |
| 筛选控件 | 两个工具页各自拥有筛选入口；可复用基础控件，但筛选结构按各自任务独立设计 |

页面专属样式不覆盖顶部导航的字号、位置、断点、Tab 尺寸、颜色变量和按钮尺寸。需要调整导航时，应修改共享导航规则，而不是在某个页面单独覆盖。

## 导航增强边界

顶部导航是页面初始 HTML 的一部分，不能依赖客户端工作区渲染后才出现。首页和工具页都需要稳定的首屏导航，服务 SEO、首屏性能和缓存。

工具页允许客户端增强导航状态，例如同步 active 状态或温度单位按钮显示。工具 Tab 和语言切换保持固定入口，不携带当前工具 query；工具状态恢复规则见 `docs/specs/20-interaction-logic.md`。这个增强只更新已有 DOM 的轻量状态，不重新渲染导航结构。

```text
工具页 DOM 顺序
┌────────────────────────────────────────────┐
│ 顶部导航                                   │
├────────────────────────────────────────────┤
│ 工具工作区                                 │
│ 各自的筛选 / 城市 / 天气 / 地图 / URL 状态  │
└────────────────────────────────────────────┘
```

## 断点

| 范围 | 顶部导航 | 工具页主体 | 页面滚动 |
| --- | --- | --- | --- |
| 宽屏 `> 1120px` | 品牌、Tab、按钮同一行 | 三列：左城市，中天气，右地图 | 工具页高度等于视口，页面本身不滚动 |
| 中屏 `<= 1120px` | 仍保持同一行，直到进入小屏断点 | 地图第一行全宽；城市列表和天气面板第二行按 `2:1` 两列排布 | 页面允许上下滚动 |
| 小屏 `<= 760px` | 品牌和按钮第一行，Tab 换行到第二行并独占这一行 | 地图第一行全宽；城市列表和天气面板第二行按 `2:1` 两列排布 | 页面允许上下滚动 |

只有宽屏三列布局和屏幕一样高。中屏和小屏都不强行同屏铺满，页面可以上下滚动，长内容由城市列表和天气面板内部滚动处理。

Landing hero 可以拥有自己的页面内容断点；这些断点只服务 Landing hero，不影响顶部导航。顶部导航的小屏断点统一以 `760px` 为准。

## 顶部导航

顶部导航在首页和两个工具页保持同一套结构：左侧品牌，中间工具 Tab，右侧温度和语言按钮。宽屏和中屏是三块同一行；进入小屏后，Tab 从第一行换到第二行。

宽屏和中屏同一行：

```text
┌──────────────────────────────────────────────────────────────┐
│ Weather Trip       [ Home | Weather map | City finder ]   °C ◎│
└──────────────────────────────────────────────────────────────┘

grid:
┌──────────────┬──────────────────────────────┬───────────────┐
│ brand        │ tabs                         │ actions       │
└──────────────┴──────────────────────────────┴───────────────┘
```

小屏换成两行，Tab 独占第二行：

```text
┌──────────────────────────┐
│ Weather Trip        °C ◎ │
│ [ Home | Map | Finder ]  │
└──────────────────────────┘

grid:
┌──────────────────┬───────┐
│ brand            │actions│
├──────────────────┴───────┤
│ tabs                     │
└──────────────────────────┘
```

小屏第二行的 Tab 是内容宽度，不是全屏宽度：

```text
正确：
┌──────────────────────────┐
│ Weather Trip        °C ◎ │
│      [ Home Map City ]   │
└──────────────────────────┘

错误：
┌──────────────────────────┐
│ Weather Trip        °C ◎ │
│ Home  | Weather | City   │
│ <------- 全宽拉伸 ------> │
└──────────────────────────┘
```

规则：

| 对象 | 规则 |
| --- | --- |
| 品牌 | 第一行左侧，单行显示，小屏字号统一为 `15px` |
| Tab 容器 | 小屏必须从第一行换到第二行，独占一整行，居中，宽度按内容收缩，最大不超过屏幕 |
| Tab 链接 | 文字垂直居中，单行显示，不拉伸到全宽 |
| 右侧按钮 | 第一行右侧，温度单位和语言切换保持同一按钮组 |
| 横向空间不足 | Tab 容器内部横向滚动，不能撑出页面级横向滚动 |

## 工具工作区

宽屏：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部导航                                                     │
├──────────────────────────────────────────────────────────────┤
│ 筛选区                                                       │
├──────────────┬──────────────┬────────────────────────────────┤
│ 城市列表     │ 天气预报     │ 地图                           │
│ 内部滚动     │ 内部滚动     │ 填满剩余空间                   │
└──────────────┴──────────────┴────────────────────────────────┘
```

中屏：

```text
┌────────────────────────────────────────────┐
│ 顶部导航                                   │
├────────────────────────────────────────────┤
│ 筛选区，可换行                             │
├────────────────────────────────────────────┤
│ 地图画布，3:2                              │
│ 图例，不计入地图画布比例                  │
├────────────────────────────┬───────────────┤
│ 城市列表，限高内部滚动     │ 天气面板，限高内部滚动 │
│ 宽度 2fr                   │ 宽度 1fr       │
└────────────────────────────────────────────┘
```

小屏：

```text
┌──────────────────────────┐
│ 顶部导航                 │
├──────────────────────────┤
│ 筛选区，自由换行         │
├──────────────────────────┤
│ 地图画布，3:2            │
│ 图例，不计入地图画布比例 │
├────────────────┬─────────┤
│ 城市列表       │ 天气面板 │
│ 宽度 2fr       │ 宽度 1fr │
│ 内部滚动       │ 内部滚动 │
└──────────────────────────┘
```

`City Finder` 和 `Weather Map` 在中屏、小屏使用同一套主体顺序：地图在前，城市列表和天气面板在下。下方两列的 `2:1` 是宽度比例，不是高度比例；两列高度按面板可用空间和最大高度规则控制，内容超出时在各自面板内部滚动。

地图比例只作用于真实地图画布。地图图例、显示区块开关、颜色条和状态浮层属于地图面板附属内容，不参与 `3:2` 画布比例计算。中屏和小屏的地图图例保持紧凑：显示区块开关和颜色图例在同一行排布，颜色条占剩余宽度。

| 区域 | 宽屏 `> 1120px` | 中屏 `<= 1120px` | 小屏 `<= 760px` |
| --- | --- | --- | --- |
| 城市列表 | 左列，随视口剩余高度铺满，列表内部滚动 | 第二行左列，宽度 `2fr`，最大高度 `min(44vh, 430px)` | 第二行左列，宽度 `2fr`，最大高度 `min(58vh, 430px)` |
| 天气面板 | 中列，窄列竖向滚动 | 第二行右列，宽度 `1fr`，最大高度 `min(44vh, 430px)` | 第二行右列，宽度 `1fr`，最大高度 `min(58vh, 430px)` |
| 地图画布 | 右列，填满剩余空间 | 第一行全宽，画布 `3:2`，图例另占高度 | 第一行全宽，画布 `3:2`，图例另占高度 |

## 筛选区

筛选区在宽屏优先单行排布，中屏和小屏允许自然换行，不用横向滚动条承载整条筛选栏。

### City Finder

`City Finder` 的筛选卡按可用宽度自然换行。`Suggested:` 和后面的快捷项属于同一个可换行组，`Suggested:` 使用更弱的文字颜色。它不作为固定左侧标签占位，后续快捷项和它一起在同一个换行流里排列。

```text
┌──────────────────────────────────────────────────────────────┐
│ Region/country │ State/province/region │ Time │ Weather │ Temperature │ ... │
│ Suggested: Comfortable sun  Dry weather  Mild temperature ... │
└──────────────────────────────────────────────────────────────┘
```

行间距保持紧凑，推荐内容可以占全宽；小屏和中屏都允许推荐项自由换行。

### Weather Map

`Weather Map` 的筛选卡在中屏和小屏保持固定结构：

| 行 | 内容 | 规则 |
| --- | --- | --- |
| 第一行 | `Region/country`、`State/province/region`、`Date` | 三者等宽横向排布 |
| 第二行 | `Layer` | 独占全宽 |

`Layer` 独占全宽后，内部图层按钮按可用宽度自然换行。宽屏可保持一行 7 个按钮；中屏和小屏都允许换行。

中屏和小屏：

```text
┌──────────────┬──────────────┬──────────────┐
│ Region/country │ State/province/region │ Date │
├──────────────┴──────────────┴──────────────┤
│ Layer                                      │
│ Weather Temperature Humidity Rainfall ...  │
└────────────────────────────────────────────┘
```

窄手机：

```text
┌────────┬────────┬────────┐
│ Region │ State  │ Date   │
├────────┴────────┴────────┤
│ Layer                    │
│ Weather Temp RH Rainfall │
│ Wind Elevation Comfort   │
└──────────────────────────┘
```

## 城市列表

中屏和小屏的城市列表把搜索和结果放在主要位置，统计摘要可以按空间压缩或省略，不参与城市行的信息结构。

城市结果行在所有版本使用同一组信息：城市名、国家 / 上级地区、右侧主指标。国家 / 上级地区放在城市名下面，字体稍小。右侧主指标用于快速判断结果，必须完整显示；左侧城市名和国家 / 上级地区可以按空间截断或换行，但不能把页面撑出横向滚动。

| 列 | 内容 | 宽度规则 |
| --- | --- | --- |
| 左侧第一行 | 城市名 | 靠左，过长时截断或按语义换行 |
| 左侧第二行 | 国家 / 上级地区 | 靠左，字号小于城市名，过长时截断或按语义换行 |
| 右侧 | 主指标 | 靠右，`min-width: max-content`，不截断 |

```text
┌────────────────────────────────────────────┐
│ 搜索城市                                   │
├────────────────────────────────────────────┤
│ 城市名                         主指标      │
│ 国家 / 上级地区                             │
│ 城市名很长时左侧截断...        主指标      │
│ 国家 / 上级地区很长时左侧截断...            │
└────────────────────────────────────────────┘
```

所有显示城市名的主要位置都要同时提供国家或上级地区：城市列表行显示在城市名下方，天气面板标题显示城市名、国家 / 上级地区和海拔。城市同名很多，不能只显示城市名让用户猜国家。

## 滚动责任

| 场景 | 滚动归属 |
| --- | --- |
| 宽屏工具页 | 页面不滚动，城市列表、天气面板等内部区域滚动 |
| 中屏工具页 | 页面可上下滚动，城市列表和天气面板有最大高度并内部滚动 |
| 小屏工具页 | 页面可上下滚动，地图画布保持 `3:2`；城市列表和天气面板按 `2:1` 宽度并内部滚动 |
| 筛选弹层 | 弹层内容超过高度时自己滚动 |
| 顶部 Tab | 空间不足时 Tab 容器内部横向滚动，不能产生页面级横向滚动 |

## 禁止项

| 禁止项 | 原因 |
| --- | --- |
| 在单个页面里覆盖共享导航规则 | 会让首页导航和工具页导航分叉 |
| 让顶部导航依赖客户端工作区渲染 | 导航是静态骨架，应服务 SEO 和首屏性能 |
| 在小屏把 Tab 拉伸成全宽三等分 | Tab 应按内容收缩并居中 |
| 让地图图例参与画布比例计算 | 画布比例只约束地图本身，图例会挤占地图可视面积 |
| 截断城市列表右侧主指标 | 主指标是列表判断依据，优先完整显示 |
| 用页面级横向滚动解决窄屏问题 | 会破坏移动端体验和可访问性 |

## 验证要求

调整顶部导航或工具页响应式布局后，至少检查以下视口：

| 视口 | 需要确认 |
| --- | --- |
| `1440px` | 工具页三列布局，页面不纵向滚动，城市/天气/地图同高 |
| `900px` | 地图在第一行且画布 `3:2`，城市列表和天气面板在第二行按 `2:1` 排布，页面可纵向滚动 |
| `390px` | 顶部 Tab 在第二行居中；地图在前且画布 `3:2`；城市列表和天气面板按 `2:1` 排布并内部滚动；`Weather Map` 筛选第一行三等分、`Layer` 全宽 |

每个视口都要确认：

```js
document.documentElement.scrollWidth <= document.documentElement.clientWidth
```

导航还要额外确认：

| 检查项 | 标准 |
| --- | --- |
| 初始输出 | 首页和工具页首屏 HTML 包含顶部导航 |
| 工具页边界 | 顶部导航在客户端工作区之前出现，且不由工作区重新渲染 |
| 三页一致 | `/`、`/city-finder`、`/weather-map` 在同一视口下 Tab 宽度、品牌字号、按钮位置一致 |
| 垂直居中 | Tab 文字在按钮内水平和垂直居中 |
