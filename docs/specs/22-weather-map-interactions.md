# Weather Map Interactions

## 文档边界

本文定义 Weather Map 的地区控件、zoom 分档、hover、点击反馈、相机行为、刷新状态、城市列表联动和 marker 密度。项目整体交互、默认排序和选中城市规则见 `docs/specs/20-interaction-logic.md`；国家分层、城市选择、区域聚合和着色口径见 `docs/specs/30-weather-coverage-design.md`；数据来源和生成链路见 `docs/specs/31-data-flow.md`；公开数据分块、请求顺序和字段结构见 `docs/specs/32-public-data-contract.md`。

## 地区控件

主地区下拉只包含全球、大区和 C2/C3 国家。C1 国家不进入下拉；它们在全球或大区地图里按国家面显示。

选择 C2 或 C3 国家后，子地区下拉只显示该国一级行政区和“全部”。C3 二级行政区不作为筛选项；URL 或本地保存状态里出现 `admin2:*` 时，按所属 `admin1:*` 恢复。

## Zoom 分档

地图边界只按当前 zoom 档切换，不按当前选中地区切换边界包。具体路径、字段和缓存策略见 `docs/specs/32-public-data-contract.md`。

| Zoom | 瓦片包 | 着色粒度 |
| --- | --- | --- |
| z1-z2 | `country` | 国家面 |
| z3-z4 | `admin1` | 一级区域；缺少一级区域时回退国家面 |
| z5-z8 | `admin2` | 二级区域；缺少二级区域时回退一级区域，再缺失时回退国家面 |

z6-z8 不生成更细的 MVT 文件，由 MapLibre overzoom z5 瓦片。这样高 zoom 仍显示二级区域细节，但请求数不会按 z6/z7/z8 继续放大。切换地区影响城市列表、marker、区域聚合、区块可见范围和自动相机；边界档位继续由 zoom 决定。

## 区块 Hover

鼠标移到可见区域时，当前区块高亮，并显示 tooltip。tooltip 使用当前语言的区域名和当前图层指标；当前指标没有数据时显示“暂无数据 / No data”。区块名称优先来自区域 summary，缺失时使用 MVT feature 的 `labelZh` / `labelEn` 兜底。

区域颜色按区块内采样点聚合。某个区块没有可用于当前指标的采样数据时，不使用相邻区域、国家平均或几何中心推断，地图显示半透明无数据面、斜线 hatch 和普通态边界线；hover 仍然高亮，并显示当前语言的区块名和“暂无数据 / No data”。海拔层使用城市地理数据计算，不依赖天气包。

地区筛选同时约束 marker 和区块。选择亚洲、欧洲或某个国家后，地图只显示该筛选范围内的天气点和区域区块；范围外的瓦片 feature 保持透明，不显示边界、斜线 hatch 或 hover tooltip，也不被解释为“暂无数据”。斜线 hatch 只用于当前筛选范围内、已经进入区域 summary 但缺少当前指标的区块。

普通态边界线不是 hover 状态的一部分。z5-z8 的二级区域边界必须在没有 hover 时可见；hover 只加深当前区块的面、阴影线和边界线，不能作为二级区域边界出现的唯一时机。

触摸设备不依赖 hover。移动端目前不提供区块详情面板；后续需要移动端区块信息时，用 tap 打开轻量信息面板，不把 admin2 加回筛选下拉。

## 地图点击

地图上的地区区块不响应 click，不改变地区筛选。地区切换只通过主地区下拉和子地区下拉完成；C3 二级行政区只用于高 zoom 着色和桌面 hover，不进入筛选下拉。

桌面端 hover 城市 marker 时，marker 显示轻量 hover ring，并弹出 tooltip。tooltip 显示当前语言的城市名、地区名和当前图层指标；天气图层显示本地化天气类型名，不显示内部天气码或图标 ID。

City Finder 的舒适度 marker 使用匹配天数表达筛选命中情况。marker 点位上的短标签只显示 `n/total`，例如 `1/14`；hover tooltip 的指标文案显示完整含义，例如 `1/14天符合筛选条件` / `1/14 days match your filters`。

城市 marker 响应 click。点击 marker 选中对应城市并刷新 forecast 面板，不改变当前地区、日期、图层或地图相机。触摸设备不依赖 hover tooltip，tap marker 直接选中城市。

## 城市列表联动

城市列表使用当前本地结果集做虚拟滚动，不使用“加载更多”。全量结果已经在浏览器内存中，虚拟列表只决定当前渲染哪些行；搜索、筛选、排序和日期变化只重算结果，不主动滚动列表。

没有任何选中城市且当前结果非空时，工具页选中列表第一项，让 forecast 面板有可展示城市。这个兜底选择不触发地图相机移动，也不触发列表滚动。

用户点击城市列表项时，选中对应城市并刷新 forecast 面板。若该城市 marker 不在地图可见区域，或太靠近地图边缘，地图把该点移动到舒适可视区域并尽量居中；这次移动不改变 zoom、地区、日期、图层或排序。

用户点击地图 marker 时，选中对应城市并刷新 forecast 面板。若该城市存在于当前城市列表，虚拟列表瞬时滚动到对应行并显示选中态；列表很长时不使用平滑滚动。若当前搜索或筛选让该城市不在列表里，列表不滚动；只要选中城市之后重新出现在列表结果里，它仍然显示选中态。

搜索、筛选、排序、日期和图层变化不覆盖已有选中城市。已有选中城市不在当前结果里时，列表没有选中行，地图没有选中 marker；forecast 面板按可用数据展示该城市，取不到数据时显示空状态。

## 区块开关与图例

地图图例区提供“显示区块 / Show regions”开关和当前图层的颜色图例。关闭后移除地区矢量图层、无数据 hatch、普通态边界、hover 高亮和 tooltip，保留城市 marker、底图、缩放和平移。图例颜色条进入弱化状态。

开关说明文案只解释区域颜色来自城市采样点聚合：数值图层取平均值，天气图层取出现最多的类型。具体聚合口径见 `docs/specs/30-weather-coverage-design.md`。

## 地图相机

地图初始化后优先恢复本次浏览会话里保存的中心点、zoom 和最近适配过的地区。用户平移、缩放或地图 resize 后，把相机写入 `sessionStorage`；严格隐私模式下无法写入时，不影响地图正常使用。

切换到 `world` 时，如果上一轮相机属于其他地区，地图回到默认世界中心和默认 zoom。切换到国家或一级区域时，等该地区数据加载完成后，用当前结果城市点计算 bounds 并 `fitBounds`；跨 180 度经线时使用最短经度区间。天气图层、日期和结果刷新不主动重置用户正在查看的位置。

地图提供全屏按钮。进入全屏后触发地图 resize，按钮变为退出全屏；按 `Escape` 也会退出全屏。

## 加载与刷新状态

首屏还没有地图数据时，地图面板显示 loading 或空状态。已有数据刷新时，地图保留旧内容，延迟显示刷新遮罩；遮罩使用 `role="status"` 和 `aria-live="polite"`，避免快请求造成闪烁。

## 城市 Marker 密度

地图缩小时必须做 marker 避让，避免点位遮住边界和底图。避让按当前 zoom、点位数量和屏幕投影网格计算；选中城市始终保留。

| 状态 | 规则 |
| --- | --- |
| 全球/大区低 zoom | 使用更大的网格，优先保留选中城市和 `rank` 更靠前的城市 |
| 国家详情低 zoom | 点位很多时继续避让，不因为进入国家页就全量显示 |
| zoom >= 6 或点位很少 | 显示全部 marker |

区域色块和 marker 使用同一批天气点。marker 解释样本位置；区域颜色解释聚合结果。

marker 避让只影响地图上实际渲染的点位密度，不在地图图例区输出城市数量或区域数量。
