# Weather Map Interactions

## 文档边界

本文定义 Weather Map 的地区控件、边界包选择、hover、点击反馈和 marker 密度。国家分层、城市选择、区域聚合和着色口径见 `docs/specs/30-weather-coverage-design.md`；数据来源和生成链路见 `docs/specs/31-data-flow.md`；公开数据分块、请求顺序和字段结构见 `docs/specs/32-public-data-contract.md`。

## 地区控件

主地区下拉只包含全球、大区和 C2/C3 国家。C1 国家不进入下拉；它们在全球或大区地图里按国家面显示。

选择 C2 或 C3 国家后，子地区下拉只显示该国一级行政区和“全部”。C3 二级行政区不作为筛选项；URL 或本地保存状态里出现 `admin2:*` 时，按所属 `admin1:*` 恢复。

## 边界包选择

地图边界包由可用数据包决定，不由“是否选了国家”直接推断。具体路径、字段和缓存策略见 `docs/specs/32-public-data-contract.md`。

| 场景 | 边界包 | 着色粒度 |
| --- | --- | --- |
| 全球/大区 | 世界边界包 | C1 国家面，C2/C3 一级行政区面 |
| C2 国家或一级行政区 | 世界边界包 | 该国一级行政区面 |
| C3 国家或一级行政区 | C3 国家详情包 | 该国二级行政区面 |

如果某个国家没有国家详情包，即使当前地区是国家级视图，也继续使用世界边界包。

## 区块 Hover

鼠标移到可见区域时，当前区块高亮，并显示 tooltip。tooltip 使用当前语言的区域名和当前图层指标。区块名称来自公开数据里的区域字典；只有边界、没有城市 summary 的区块，也必须有可展示的本地化名称。

地理区块是否可见由边界包决定，城市和天气数据只决定当前指标有没有填色。某个区块有边界但没有代表城市，或有代表城市但缺少当天/当前筛选条件的天气时，地图显示白色半透明面和边界；hover 仍然高亮，并显示当前语言的区块名和“暂无数据 / No data”。海拔层使用城市地理数据计算，不依赖天气包。

触摸设备不依赖 hover。后续需要移动端区块信息时，用 tap 打开轻量信息面板，不把 admin2 加回筛选下拉。

## 地图区块点击

地图点击只改变视图聚焦，不替代筛选下拉的层级规则。C1 国家保持在全球或大区语境里；C2/C3 国家可以进入国家级视图；一级行政区可以进入该国的一级区域视图；C3 二级区域只展示 hover 或 tap 信息，不进入筛选下拉。具体覆盖层级和点击对象行为见 `docs/specs/30-weather-coverage-design.md`。

## 城市 Marker 密度

地图缩小时必须做 marker 避让，避免点位遮住边界和底图。避让按当前 zoom、点位数量和屏幕投影网格计算；选中城市始终保留。

| 状态 | 规则 |
| --- | --- |
| 全球/大区低 zoom | 使用更大的网格，只保留高权重点位 |
| 国家详情低 zoom | 点位很多时继续避让，不因为进入国家页就全量显示 |
| zoom >= 6 或点位很少 | 显示全部 marker |

区域色块和 marker 使用同一批天气点。marker 解释样本位置；区域颜色解释聚合结果。
